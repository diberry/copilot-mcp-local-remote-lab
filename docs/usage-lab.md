# Usage lab

> This is a learning repository, not a production reference architecture.

Invoke `diagnostics`, reset, add `synthetic-alpha`, `synthetic-beta`, and `synthetic-gamma`, list, complete `todo-2`, and list. The custom agent constrains this order, the skill explains experiment controls, and the client hook records content-free timing metadata. Those client extensions remain client-side. The MCP server returns wrappers with `requestId`, `operation`, `outcome`, `serverVersion`, and `data` or normalized `error`.
