# Contributing

This learning repository is not a production reference architecture. Use Node.js 22.14.0 and npm 10.9.2, run `npm ci`, then `npm run check`. Generated `plugins/` and `artifacts/` content is never hand-edited or committed. Update canonical source and regenerate it. Add tests for both adapters, preserve the one-variable baseline, and never add credentials, real todo content, prompts, headers, identities, or environment values to fixtures. Report vulnerabilities according to [SECURITY.md](SECURITY.md).
